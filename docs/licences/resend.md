# Resend (SDK npm `resend` 6.34.1)

- Usage : envoi des emails transactionnels (story 4.4), côté serveur seulement.
- Licence du paquet : MIT (voir `node_modules/resend/package.json`, champ `license`, vérifié à l'installation).
- Aucun fichier du paquet n'est copié dans le dépôt ; il est installé par npm (`package.json`, version exacte).
- Le service Resend lui-même est soumis à ses conditions d'utilisation ; la clé d'API est une variable d'environnement (`RESEND_API_KEY`), jamais commitée.
